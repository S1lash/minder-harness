# /minder:harness:add-skill

A recurring task looks like it deserves a repeatable procedure. **Do not jump to creating
one.** Run the critical gate in `doctrine/skill-creation.md` first — first match stops:

1. **Reclarify intent.** The person may not know what they actually want — surface it.
2. **Already have one?** A skill (or a rule) already covers this → reuse it, don't duplicate.
3. **Close but missing a nuance?** → extend/improve the existing one, don't fork.
4. **Narrow / one-off?** → a rule, or just do it. Not a skill.
5. **Genuinely new + reusable + uncovered?** → author it per `doctrine/skill-creation.md`,
   decomposing onto `tools/` + `instruments` by default (`doctrine/tool-vs-instrument.md`) —
   don't inline mechanical work.

**Always justify** the outcome to the person (created / reused / extended / declined — and
why). The person can override, but push back with a reason first — you defend the base's
health (`rules/harness-stewardship.md`).
